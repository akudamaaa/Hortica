# Hortica — сайт яхты «Хортица»

Первая локальная версия сайта на Django 5.2 и SQLite. Тексты и архивные фотографии взяты с действующего сайта и формы регистрации по ссылкам ниже. Не все материалы старого сайта перенесены полностью; список экипажа и даты новых выходов требуют подтверждения.

## Запуск на Windows

Требуется Python 3.12 или новее и Git.

    py -3 -m venv .venv
    .\.venv\Scripts\Activate.ps1
    python -m pip install -r requirements.txt
    python manage.py migrate
    python manage.py runserver

Открой сайт по адресу http://127.0.0.1:8000.

Файл .env содержит локальный секретный ключ и исключён из Git. Не публикуй его. При первом запуске скопируй .env.example в .env и добавь ключ, сгенерированный командой: python -c "import secrets; print(secrets.token_urlsafe(48))".

Если запуск PowerShell запрещает активацию окружения, вызывай Python напрямую:

    .\.venv\Scripts\python.exe -m pip install -r requirements.txt
    .\.venv\Scripts\python.exe manage.py migrate
    .\.venv\Scripts\python.exe manage.py runserver

## Доступ в админку

В публичной навигации нет ссылки на админку. Перейди вручную на http://127.0.0.1:8000/admin/ и войди под учётной записью с правом staff.

Публичной регистрации администраторов нет. Создай два отдельных аккаунта вручную, запустив команду ниже дважды и задав разные логины и пароли:

    python manage.py createsuperuser

Команда запросит логин и пароль в терминале. Не помещай пароли в исходный код, .env.example или Git. Пока панель показывает только заглушку и не позволяет менять контент.

## Страницы первой версии

- Главная — вводный текст о яхте и проекте.
- История — подтверждённые сведения из исторического раздела; расхождение по году спуска на воду отмечено отдельно.
- Экипаж — вводный текст и место для актуального состава.
- Походы — выборка архивных маршрутов и фотографии исходного сайта.
- Регистрация — текст и поля по Google-форме; отправка отключена, данные не передаются и не сохраняются.
- /admin/ — отдельный вход и защищённая заглушка панели управления.

## База данных

Локальная база SQLite хранится в db.sqlite3 и игнорируется Git. Миграции Django создают служебные таблицы аутентификации и сессий, но пользовательских записей, администраторов и данных сайта пока нет. После миграций база остаётся пустой до создания администратора. Не добавляй db.sqlite3 в репозиторий.
