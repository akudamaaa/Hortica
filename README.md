# Сайт яхты «Хортица»

Новая версия сайта с полностью перенесёнными текстовыми разделами, архивом фотографий и списком походов с исходного сайта. Проект работает локально на Django 5.2 и SQLite; публичная регистрация и отправка заявок пока отключены.

## Запуск на Windows

Требуются Python 3.12 или новее и Git.

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Открой http://127.0.0.1:8000. Если PowerShell запрещает активацию окружения, запускай команды через `.\.venv\Scripts\python.exe`:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py runserver
```

Файл `.env` содержит локальный секретный ключ и исключён из Git. Для нового клона скопируй `.env.example` в `.env` и добавь секретный ключ, созданный командой `python -c "import secrets; print(secrets.token_urlsafe(48))"`.

## Перенесённые страницы

Оригинальные адреса `.htm` сохранены, поэтому старые внутренние ссылки продолжают работать:

- Главная — `/` и `/index.htm`
- О проекте — `/project.htm`
- История — `/history.htm`
- Экипаж — `/crew.htm`
- Походы — `/track.htm`
- Координаты — `/koord.htm`
- Прошлое — `/oldspice.htm`
- Походы с отдельными рассказами — `/2006.htm`, `/2007.htm`, `/2009.htm`, `/2010.htm`

Всего перенесено 11 страниц старого сайта, включая статьи, маршруты, якорные ссылки и связанные материалы. В каталоге `assets/legacy/` находятся 547 исходных графических файлов, включая изображения для интерактивных состояний экипажа. На странице походов собран общий архив из 295 уникальных фотографий: снимки можно увеличить и листать. Список `IMAGE-CAPTIONS.csv` связывает каждый файл, страницу источника и подпись. Где исходная страница не содержала подписи, это отмечено явно.

Фотографии возвращены в текстовые страницы в порядке исходной разметки. На странице экипажа участники показаны отдельными карточками с соответствующими портретами. Интерфейс оформлен в пиксельном стиле по приложенному логотипу; навигация раскрывается из меню в правой части шапки, логотип меняется при наведении.

Новые разделы: `/registration/` — неотправляемый макет формы, `/admin/` — закрытый вход и заглушка панели управления. Ссылки на админку в публичной навигации нет. Старый адрес `/archive/` открывает общий фотоархив на странице походов; отдельная страница не добавляется.

## Вход в админку

Перейди вручную на http://127.0.0.1:8000/admin/. Вход доступен только учётным записям с правом `staff`. Публичного создания учётных записей нет. Когда потребуется, создай два аккаунта вручную через `python manage.py createsuperuser`, задавая каждому отдельный логин и пароль. Сейчас база не содержит ни пользователей, ни заявок.

Панель пока показывает заглушку. Учёт выходов яхты, управление содержимым и настройка регистрационной формы относятся к следующим этапам и не включены без отдельного согласования.

## База данных и миграции

Используется локальная SQLite база `db.sqlite3`. В ней применены миграции Django для входа, ролей и сессий; данных пользователей и сайта нет. Файл базы игнорируется Git. Когда будут согласованы модели страниц, заявок и выходов, изменения схемы следует вносить миграциями Django, не редактируя базу вручную.

## Источники и перенос

Материалы перенесены с [старого сайта яхты «Хортица»](https://www.xortica.ru/), в том числе [проект](https://www.xortica.ru/project.htm), [история](https://www.xortica.ru/history.htm), [экипаж](https://www.xortica.ru/crew.htm), [походы](https://www.xortica.ru/track.htm), [координаты](https://www.xortica.ru/koord.htm), фотоархив прошлого и рассказы о походах 2006, 2007, 2009 и 2010 годов.

Тексты исходных страниц перенесены без редакторской переписи, за исключением подтверждённой пользователем даты: яхта сошла на воду и совершила первый поход в 1960 году. Исторические маршруты показываются как архивные записи, не как актуальное расписание.
